## Overview

MAC-OS Portfolio reimagines a traditional developer portfolio as an interactive desktop environment inspired by macOS. Instead of navigating a conventional set of pages, visitors can explore different applications and windows to learn about my background, technical skills, projects, and professional experience.

The project combines interface design with interactive frontend development to create a distinctive way to present my work.

## Features

- **Interactive desktop:** Explore portfolio content through a desktop-style environment.
- **Dock and application launcher:** Open portfolio applications through familiar desktop navigation.
- **Window management:** Interact with application windows using desktop-inspired controls.
- **Built-in terminal:** Explore portfolio information and access supported commands and links.
- **About and skills:** Learn about my background, experience, and technical skills.
- **Project showcase:** Explore selected projects, repositories, and live demos.
- **Resume viewer:** View my resume directly within the portfolio.
- **Contact and social links:** Access my professional profiles and contact information.
- **Desktop customization:** Explore the available wallpaper and settings options.

## Getting Started

Run the project locally to explore the interface and its components.

### Prerequisites

- [Node.js](https://nodejs.org/) installed
- npm (included with Node.js)
- Git installed

### Installation

1. Clone the repository:

   ```bash
   git clone https://github.com/Vishnu-222/MAC-OS-Portfolio.git
   ```

2. Navigate to the project directory:

   ```bash
   cd MAC-OS-Portfolio
   ```

3. Install dependencies:

   ```bash
   npm install
   ```

4. Start the development server:

   ```bash
   npm run dev
   ```

5. Open the local URL displayed in your terminal, typically `http://localhost:5173`.

### Production Build

To create an optimized production build:

```bash
npm run build
```

To preview the production build locally:

```bash
npm run preview
```

The generated production files are placed in the `dist` directory.
